# SURE-Tagger interactive demo

The [live page](https://me-chuan.github.io/sure-tagger/) offers five recorded Tag-Bench clips and five controlled LayeredSpeech-500 scenes. It plays each clip, shows SURE-Tagger fields, compares three model descriptions, and filters clips by tag conditions. Synthetic scenes also link to their renderer ground truth and field-level review. These examples are not an ASR performance report.

## Run locally

From this repository's root, run `python3 sure-tagger-main/demo/serve.py`, then open <http://127.0.0.1:8765/sure-tagger-main/demo/>. English is the default; use the `中文` switch for Chinese.

The bundled data is generated by `node sure-tagger-main/demo/build-fixture-data.mjs` from the committed sample records. To display your own records, provide `sure-tagger-main/demo/data.js` with `window.DEMO_DATA` in the same sample format and open `?data=local`.
